## Zotero PaperLens 0.1.3

PaperLens creates a reading session for each PDF and translates selections using the paper's overall context.

- Read all extractable paper text, retain progress, and build an overview, detailed notes, and a glossary.
- Translate selections with paper-wide explanations and source passages when available.
- Add source-matched native Zotero highlights with a local visibility toggle.
- Use OpenAI, Anthropic, DeepSeek, or a custom OpenAI-compatible endpoint.
- Work from the reader sidebar with a Chinese or English interface.

**Install:** download `zotero-paperlens-0.1.3.xpi`, then choose **Tools → Plugins → gear menu → Install Plugin From File…** in Zotero. `SHA256SUMS` contains the installation package's checksum.

Targets Zotero 9/10 desktop; native checks have passed on Windows with Zotero 10.0.6. Zotero 9, macOS, and Linux are not yet verified. Scanned PDFs need OCR; figures are not analyzed visually. Real model quality and complex PDF text order still require evaluation. Reading sends paper text to your configured endpoint and may incur API fees.

## 中文说明

PaperLens 为每篇 PDF 建立阅读 session，并结合全文理解翻译用户选文。

- 阅读全部可提取的论文文字，保存进度，生成概述、详细笔记与术语表。
- 结合论文上下文提供译文、解释，以及可用的原文依据。
- 创建经过原文定位的 Zotero 原生高亮，可在本机阅读器中隐藏或显示。
- 支持 OpenAI、Anthropic、DeepSeek 和自定义 OpenAI 兼容接口。
- 在阅读器侧栏使用，界面可选中文或英文。

**安装：**下载 `zotero-paperlens-0.1.3.xpi`，在 Zotero「**工具 → 插件 → 齿轮菜单 → 从文件安装插件…**」中选择安装。`SHA256SUMS` 提供安装包校验值。

目标为 Zotero 9 / 10 桌面版，已在 Windows、Zotero 10.0.6 通过原生检查；Zotero 9、macOS 和 Linux 暂未验证。扫描 PDF 需要先 OCR，图片不进行视觉分析。真实模型效果和复杂排版的提取顺序仍需评估。读取会将论文文字发送给配置的服务，可能产生 API 费用。
