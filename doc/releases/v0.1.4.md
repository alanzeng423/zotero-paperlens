## Zotero PaperLens 0.1.4

Improves DeepSeek compatibility and recovery from truncated model responses.

- Uses `deepseek-flash` as the DeepSeek preset for DeepSeek-V4.1-Flash.
- Requests non-thinking JSON output for DeepSeek reading notes and translations, with a larger output budget.
- Retries a truncated response once with a larger token allowance, up to 32,768 tokens; usage includes both responses when recovery succeeds.
- Keeps incomplete JSON out of saved reading notes and preserves completed fragments for resuming.

Install `zotero-paperlens-0.1.4.xpi` through **Tools → Plugins → gear menu → Install Plugin From File…**. Existing credentials and reading sessions are retained. To resume an interrupted reading, keep the same paper and settings and select **Resume**.

The release passes 44 offline checks. These checks simulate provider responses and do not establish live model quality. Targets Zotero 9/10 desktop, with native integration verified on Windows with Zotero 10.0.6.

## 中文说明

改进 DeepSeek 接口兼容性和模型输出截断后的恢复。

- DeepSeek 预填模型改为 `deepseek-flash`，对应 DeepSeek-V4.1-Flash。
- 阅读笔记与翻译明确使用非思考 JSON 输出，并增加输出预算。
- 截断时提高预算重试一次，上限为 32,768 tokens；恢复成功后，两次响应都会计入用量。
- 不将半截 JSON 保存为阅读笔记，已完成的分段保留，支持继续读取。

在 Zotero「**工具 → 插件 → 齿轮菜单 → 从文件安装插件…**」安装 `zotero-paperlens-0.1.4.xpi`。已有凭证和阅读 session 会保留。继续中断的阅读时，请保持论文和设置不变，点击「**继续读取**」。

已通过 44 项离线检查。测试模拟服务响应，不代表真实模型效果已验证。目标为 Zotero 9 / 10 桌面版，原生集成已在 Windows、Zotero 10.0.6 验证。
